জনকল্যাণে নবজাগরণ — বিনামূল্যের প্রাথমিক ওয়েব অ্যাপ ডেমো

ফাইলসমূহ:
- index.html: মোবাইল-উপযোগী সাইট ও ইন্টারঅ্যাকটিভ ডেমো
- manifest.json: হোম স্ক্রিনে ইনস্টলযোগ্য PWA-এর নাম/সেটিং
- sw.js: সীমিত অফলাইন ক্যাশ

গুরুত্বপূর্ণ সীমাবদ্ধতা:
1. সদস্য আবেদন localStorage-এ শুধু একই ব্রাউজার/ডিভাইসে সংরক্ষিত হয়।
2. কোনো ডেটাবেস, অনলাইন সিঙ্ক, বাস্তব লগইন, নিরাপদ অ্যাডমিন প্যানেল বা পেমেন্ট নেই।
3. এটি সরাসরি Play Store APK নয়।
4. বাস্তব সদস্যদের ব্যক্তিগত তথ্য দিয়ে এই ডেমো ব্যবহার করবেন না।
5. জনসাধারণের জন্য চালু করতে HTTPS হোস্টিং এবং নিরাপদ ব্যাকএন্ড/ডেটাবেস দরকার।

মোবাইল থেকে ব্যবহার:
- ZIP ফাইল আনজিপ করে index.html খুলে প্রোটোটাইপ দেখতে পারেন; সব ব্রাউজারে ফাইল মোডে সব সুবিধা নাও চলতে পারে।
- PWA install/offline সুবিধার জন্য ফাইলগুলো HTTPS-এ হোস্ট করতে হবে।
- বিনামূল্যে প্রকাশের সম্ভাব্য পথ: GitHub Pages। GitHub অ্যাকাউন্টে নতুন repository তৈরি করে এই ফাইলগুলো upload করুন, Settings > Pages-এ branch থেকে deploy করুন। মেনুর নাম পরিবর্তিত হতে পারে।
